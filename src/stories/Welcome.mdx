# 🎪 BUM Tiana Fest 2026 — Storybook de Components

Benvinguts al catàleg interactiu de components de **BUM Tiana Fest 2026**.

Aquest Storybook permet explorar, provar i desenvolupar tots els components de la interfície de manera aïllada:

- **Navigation**: Barra de navegació principal (`Navbar`) i peu de pàgina (`Footer`).
- **Sections**: Seccions de la pàgina principal (`Hero`, `ConceptSection`, `SpeakersSection`, `WorkshopsSection`, `ScheduleSection`, `VenuesSection`, `GastronomySection`, `PricingSection`, `TwoLBSection`, `FaqSection`).
- **Pages / Views**: Pàgines de detall per a ponents (`SpeakerDetailPage`) i tallers pedagògics (`WorkshopDetailPage`).
- **Components**: Carrusels dinàmics (`HeroCarousel`, `PartnersCarousel`).

---

### Scripts disponibles:
- `npm run storybook`: Arrenca el servidor de desenvolupament de Storybook al port `6006`.
- `npm run build-storybook`: Compila la documentació estàtica per a desplegar a qualsevol servidor web.
